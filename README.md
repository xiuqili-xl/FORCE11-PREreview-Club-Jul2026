# FORCE11 PREreview Club Jul 2026

This repository contains code written as part of the [FORCE11 PREreview Club](https://prereview.org/clubs/force11) in July 2026.

During this review, we explored the following preprint:

> Cobb-Lewis D, Synder D, Dumanis S, Thibault R, Marebwa B, Clark E, St. Clair L, Kirsch L, Durborow M, Riley E. 2024. Investing in open science: Key considerations for funders. bioRxiv. doi:[10.1101/2024.12.09.627554](https://doi.org/10.1101/2024.12.09.627554)

The accompanying data for this preprint are available on Zenodo:

> Cobb-Lewis D, Synder D, Dumanis S, Thibault R, Marebwa B, Clark E, St. Clair L, Kirsch L, Durborow M, Riley E. 2024. Investing in Open Science: Key Considerations for Funders. doi:[10.5281/ZENODO.14262739](https://doi.org/10.5281/zenodo.14262739)

Our collaborative review will be shared on PREreview.

## Files

- `code.R`: code used to inspect the data and recreate analyses from the preprint
- `figure-apc-vs-impact-factor.png`: exploratory recreation plot graphing article processing charges (APCs) against journal impact factor
- `figure-apc-vs-row-number.png`: diagnostic plot comparing APCs with dataset row order


## Data availability

This repository does *not* contain the source datasets. `code.R` reads them directly from the [Zenodo deposit](https://doi.org/10.5281/zenodo.14262739).

Please consult the Zenodo record for dataset authorship, version information, licensing, and citation guidance.
